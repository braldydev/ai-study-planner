# AI Study Planner 📚

AI-powered study planner built with Next.js and OpenAI API.

## Features
- AI-generated study plans
- Interactive flashcards
- Study history
- PDF export
- Multiple study levels
- Copy plan button
- Responsive UI

## Tech Stack
- Next.js
- React
- Tailwind CSS
- OpenAI API
- jsPDF
